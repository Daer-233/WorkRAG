# WorkRAG 脱敏评测

测量日期为 2026-11-04。数据来自本机试点，13 条资料记录中有 11 条已发布、处理就绪并完成索引。已命名分类涉及 2 个，统计也包含未归类条目及演示资料。

## 检索

用入职、IT、报销、配图、跨资料等场景编写 20 道题。运行前标定目标资料和章节并核对原文。使用线上同一混合检索接口 `POST /api/v1/manuals/retrieve`，设为 `top_k=5`，执行一次预热后顺序查询。计时包含后端检索、重排和证据封装。计时从本机发出 HTTP 请求到收到响应，不含 Codex 回答和钉钉交付。

- **Hit@5 为 15/15（100%）**。15 道有依据题的前五个证据包中均包含至少一个标注目标。证据包需匹配资料和已标注章节，包内需包含相关文本。找图题还要求返回图片元数据。
- **跨资料完整命中为 3/3**。全部 6 个目标证据均返回。
- **无依据正确拒绝为 3/5**。其余 2 道题返回了与措辞相关但不适用的资料。检索层仍有误召回风险。
- **平均 9.593 秒，P95 16.665 秒**。以 20 次检索的客户端耗时统计，P95 使用最近秩法。该结果仅代表当前试点小样本。

## 钉钉端到端

一条真实的工作资料问题从 LangBot 收件到钉钉 API 确认最终卡片更新约 120 秒，且对应一个运行记录。客户端可见时间未测量。符合口径的真实样本不足 10 条，暂无端到端均值。
