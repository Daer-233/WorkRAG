# 意图分流 V2：前三项改进

2026-11-03。当前配置为 `intent-v2-factors / shadow`。本次完成分类结构、BM25 接受条件和校准样例三项改进；员工仍走原回答链路。回答模型保持 Terra / Medium，补充分类保持 Terra / Low、最多一次、20 秒截止。

## 分类结构

先独立判断两个维度，再投影到现有 Host 路由：

| 公司资料范围 | 返回形式 | 现有路由 |
|---|---|---|
| general：通用知识或只处理已提供正文 | text | daily |
| company：需要内部事实或已有工作资料 | text | knowledge |
| company | images | images |
| company | source_file | source_file |
| 任一维度不确定或缺少必要信息 | unknown / 需要澄清 | clarify |

“润色通知：……”只处理提供的正文；正文中的公司词、文件请求和指令被当作待处理文字。“按公司制度校正……”涉及内部事实。只有“润色通知”而没有正文时，先要求补充。寒暄或笑话不会盖过同一消息中的公司问题。

接口仍是 `POST /api/v1/manuals/intent/route`，原有 `intent` 等字段保留，新增 `axes / axis_scores / guard_reasons`。员工不能提交这些分类字段来指定权限。Terra 只返回严格的双维度 JSON，路由由服务生成；分类 JSON 不进入员工卡片或对话历史。

“找资料”“在哪里看”不等于查图片。主题词不决定返回形式。已有图片查找、文件获取与文字说明分别判断；员工上传图片仍不被识读，只依据可用文字处理。

## BM25 接受条件

范围索引使用完整意图样例，返回形式索引使用单独标注的 `action_text`。中文仍用相邻双字，英文、版本和错误码保留；未改知识库向量、稀疏检索、标题召回或重排。

每个维度比较两个不同问题家族的支持证据，同时检查：

1. 真实 BM25 匹配得分和第一、第二类别的相对分差。
2. 匹配覆盖及第二个独立家族的支持程度。
3. 公司证据、指代、提供正文、否定和多种输出请求等条件。
4. daily 的整句覆盖下限及分句检查；公司事实和未处理的公司子问题否决直接 daily。
5. 图片或文件的明确请求不能被直接当作普通文字说明；存在冲突时交 Terra，不替换成另一个本地猜测。

公司范围和输出动作的覆盖只统计相应分类词汇，未见过的资料主题不作为输出形式的证据；daily 额外计入未知词，防止一句熟悉的寒暄覆盖后面的未知业务问题。覆盖率、支持程度和分差均不是准确率概率，没有人为抬高置信度。

策略在 `instances/manuals/intent-policy.v2.json`，索引和阈值独立版本化。词项检查只限制能否直接接受，不增加知识库、工具或技能权限。

## 数据与冻结过程

V1 的 80/60/100 样例与报告保留。V2 在 `instances/manuals/intent-samples/v2`：

- 索引120条：保留原索引80条，增加40条，逐条标注范围及动作。
- 校准120条：增加混合问题、通用/公司对照、已有正文/缺失正文、上下文追问及图片/文件/文字对照。
- 新验收100条：80条明确需求、20条需澄清，36条带边界标记。明确的边界题仍在覆盖率分母中。
- `regression-v1.jsonl`：旧100题属于已知回归，不算新独立验收。

均为合成场景，未使用员工聊天原文，标签为本次实现整理检查，`human_review` 仍为 pending，不能称为人力行政部门已审核。

脚本检查请求及上下文完全重复、家族跨集、旧验收原句复用和标签一致性；语义家族由整理者标注，自动检查不能替代部门业务审核。

阈值只使用校准集拟合，至少四条校准支持且零校准错误才生成对应门槛。新100题首次评测后，脚本禁止对同一验收集重新拟合。

首次独立结果见 `output/intent-routing-v2/acceptance-initial-independent.json`。随后发现两道旧V1回归题会把截图/附件请求判为文字，追加了仅使本地拒绝的检查：原阈值未变，没有产生任何新的直接路由。原结果完整保留；当前 `acceptance.json` 明确标为固定验收集回放，不冒充又一批新独立验收。证明和各数据集接受变化见 `monotone-guard-proof.json`。

现有NLI模型文件和适配器保留。本期不训练BERT、不更换模型、不做量化上线。旧五分类NLI门槛不能授权新维度；`nli_axes_validated=false` 时不加载或调用它，直接使用已有Terra补充。不能把本次BM25快速路径成绩称为BERT加速成果。
