## 启停与回退

日常使用原 start-knowledge.bat / start-local.ps1 / status-local.ps1 / stop-local.ps1，已管理 Pi 服务。

在项目根目录执行 .\.venv\Scripts\python.exe deployment/select_agent_engine.py legacy --target both 可回退原 Agent 循环；重新启用用 pi --target both。脚本在修改前备份处理器配置，保留模型、工具授权、资料和卡片。不要运行 configure_agent.py 覆盖用户的真实模型配置。

源码 apps/pi-harness、apps/workrag-agent、plugins/WorkRAGGraph。安装包 workrag-WorkRAGGraph-0.4.1.lbpkg 在本地 runtime 目录。迁移机器还需 Node >=22.19，并在 apps/pi-harness 用 npm ci --ignore-scripts 安装依赖；仅导入插件包不会安装 Node 服务。
