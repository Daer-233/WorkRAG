# 回答结尾询问源文件需求 · 2026-11-03

工作知识助手在回答确实引用本次检索资料、且对应来源文件存在于独立知识库归档目录时，结尾询问一次：

> 需要这份资料的源文件吗？

对于仅保存 MinerU Markdown 整理稿的资料：

> 需要这份资料的整理稿文件吗？

多份来源可询问需要哪份。普通闲聊、无证据、知识库繁忙及没有可用归档文件时不提醒。不把图片条目的标题当作原文件，不把 Markdown 冒称原始 PDF/PPT/Word。

本次只接入需求提醒。文件发送还未完成联调，不能表示已经发送，也不生成虚假的下载地址或员工无法使用的本机链接。员工回复需要后，先确认资料；没有可用文件发送工具时说明尚未接通，不编造发送成功或领取途径。

实现：`apps/backend/app/manuals/source_offer.py` 检查受控目录中的实际归档文件；`service.py` 与 `langbot.py` 传递 `source_file.available/name/kind/offer_text/attachment_delivery_verified` 并给回答模型提供提醒规则。保留原有检索、引用和图片字段。规则也已追加到 Codex 工作区的 `AGENTS.md`；接入脚本重新生成工作区时会继续保留同类约束。

验证：来源与 LangBot 检索相关 13 项测试通过，覆盖文件缺失、跨目录文件拒绝、整理稿区分、来源元数据和原有检索接口兼容。未向钉钉主动发送测试消息。
