## 权限证据与边界

- MCP 无访问令牌时实际返回 401；运行范围签名由服务端验证。工具返回资料再次检查白名单、发布状态与版本，模型不能指定身份或权限范围。
- 实际匿名审核请求返回 401，管理员 Page 查询、编辑、发布、下架请求成功。
- 对当前 Host 的真实路由和授权模块检查 `resource.manage` 守卫，验证 viewer/operator 拒绝、developer/admin/owner 允许；**未另建普通成员账号执行完整登录后的 HTTP 验收**。
- 现有 Local Agent 配置在重启前后比较保持一致，新处理器未绑定真实机器人。WorkRAG 原始管理与资料检索通过本机接口保留可用。

## 验收后的用户调整

完成重启验收后，用户主动卸载原“内置 Agent”插件并删除原“本地 Agent”流水线，随后在本会话中明确确认“是，我主动删除的，保留现状”。交付保留该现状，没有自动重建原组件。此调整与前述保留原配置的历史验收记录分开记录，后续复验脚本读取本机确认记录，按用户选择检查原组件保持删除状态。
