克隆代码不会恢复知识库或本机 Codex 登录。恢复须使用另外保存的本机私有数据、数据库备份和已授权登录，按 `docs/history/intent/knowledge-intent-routing-v1.md` 操作。不要为了让代码仓库“完整”而把资料和凭据加入 Git。
