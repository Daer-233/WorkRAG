# 意图分流 V3 验收记录

V3 将专用 BERT 接在 BM25 后面，仍采用影子模式。模型复用已校验的中文 BERT 编码器，训练顶层、池化层及三个分类头。检查点选自第 10 轮，权重增量约 33 MB。训练、开发、校准与验收数据分别为 784、114、148、148 条。

| 同一组合成留出题 | 明确问题本地覆盖 | 本地接受准确率 | 公司问题误入日常 |
|---|---:|---:|---:|
| V2 | 63/124（50.8%） | 63/63（100%） | 0 |
| V3 仅 BM25 | 54/124（43.5%） | 54/54（100%） | 0 |
| V3 BM25＋BERT | 121/124（97.6%） | 128/132（97.0%） | 0 |

覆盖率提升主要来自 BERT。本地分类全路径 P95 为 753 ms，独立 BERT 进程预热后 P95 为 511 ms，冷加载约 90 秒。77 项独立测试通过，其中包含分类冲突、故障回退、上线保护、卡片和原回答模型配置。合成样例共享常见问句模板，结果仍需真实影子观察及人工审核。

V3 留出集有四个多轮找图请求被判断为知识问答，问句是“还有现场的图能给我看看吗”，对应四段不同历史。V1 已知回归为 63/63，V2 已知回归为 67/71（94.4%），V2 错误集中在本应澄清的边界问题。旧题回归低于 95%，正式分流门槛未通过。模型和阈值在打开留出集前已固定。
