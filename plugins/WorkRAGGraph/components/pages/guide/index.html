这些入口分别做什么？

日常调试用“调试助手”；配置机器人问答用“问答流水线”；上传和发布原始资料进入 WorkRAG。

消息入口 → 问答流水线 → 问答引擎插件（LangGraph → Pi Agent） → LangBot 模型 / 资料检索工具（MCP） → WorkRAG

本机调试也可以从“调试助手”直接调用同一个引擎。LangGraph 管理记忆和资料确认，Pi 执行内部问答与工具循环；模型仍由 LangBot 授权。

资料在哪里管理？

正式原件、解析结果、发布状态和检索索引在 WorkRAG 管理。LangBot 中配置模型、处理器、工具授权，并审核标准问答。左侧两个备用知识库没有自动连接到 WorkRAG。
